# Beyond the Wing — Aerospace Explained

This is the first web version of the Keynote design. The three Keynote slides are used as the visual pages, with transparent clickable hotspots layered over the exported images.

## Pages
- `index.html` — Home
- `explore.html` — Explore/categories
- `about.html` — About

## Notion connections
The six Explore category hotspots open the corresponding public Notion pages.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `aerospace-explained`.
2. Upload all files in this folder, including the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. GitHub will give you the public site URL.
